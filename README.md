# Floating Google (Android)

Jendela Google mengambang di atas aplikasi lain.
- Geser bar biru untuk memindahkan, tarik ◢ untuk ubah ukuran
- "—" mengecilkan jadi bubble "G" (ketuk untuk membuka lagi)
- "✕" menutup

## Instal dari GitHub
1. Buka tab **Releases** di repo ini, unduh `FloatingGoogle.apk`.
2. Izinkan "Instal dari sumber tidak dikenal", lalu instal.
3. Buka app, tekan **Mulai**, aktifkan izin "Tampil di atas aplikasi lain".

## Build sendiri
Push ke GitHub, lalu GitHub Actions membangun APK otomatis.
Untuk membuat Release: `git tag v1.0 && git push origin v1.0`.
